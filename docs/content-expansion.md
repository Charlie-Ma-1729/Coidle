# 更多店家、擴建、更多內容

## 業態：41 → 84 種
每個區域都多了一批業態（資料在 `shared/src/game/data.ts` 的 `CATEGORIES`）。每個業態有：參考售價、成本率、容量、各客群需求、開店成本；大部分新業態另有 **`minLevel`**（商場等級要到才開得出來，區域一開放就能開的是基本款）。

| 區域 | 新增業態 |
|---|---|
| B1 美食街 | 餃子・中華小吃、飯糰・便當、鯛魚燒、關東煮、蕎麥麵、麵包烘焙坊、唐揚雞、鮮榨果汁 |
| 1F 時尚與生活 | 便利商店、美妝、鞋履、飾品、玩具模型、花店 |
| 娛樂區 | 保齡球館、夾娃娃機專區、密室逃脫、展演空間、手作體驗工房 |
| 3C 與文創 | 相機器材、動漫周邊、遊戲專賣、唱片・黑膠行、藝廊 |
| 生活服務 | 美甲、瑜伽教室、牙科診所、補習班、寫真館、3C・衣物修繕 |
| 高樓層餐飲 | 豬排、精釀啤酒屋、鰻魚飯、葡萄酒吧、鐵板燒、懷石料理 |

| 商務與旅宿 | 膠囊旅館、旅行社、行李寄放、影印・郵務 |

連帶處理：進貨供應商家族（`FAMILY_OF`）、日本法規許可（`LICENSES`：食品營業許可、深夜酒類、旅館業、旅行業登錄、醫療機關開設…）、消費稅率（外帶類食品 8%、保險牙科診療免稅）、圖示、招商候選與機器人策略。各區基本店面數也增加（10／10／7／8／8／10／4／6）。

## 擴建
在 **樓層 → 區域** 底下的「🏗️ 擴建店面」：
- 每區各有擴建上限（B1／1F／高樓層餐飲 4 次、娛樂／文創／生活服務／商務 3 次、廣場 2 次）。
- 費用 ¥2,000,000 × (0.7＋0.3×樓層階級) × (1＋0.45×已擴建次數)；越高樓層、越後面的擴建越貴。
- 第 3 次起要更高的商場等級（區域解鎖等級＋⌊已擴建次數／2⌋）。
- 立即完成；新店面編號接在最後（`slot.id` ＝ 陣列位置）。擴建費計入固定資產稅的評價額。
- 指令：`{ type: "expandZone", zone }`。狀態版本升到 **v11**（舊存檔自動補上新增的基本店面）。

## 研發工坊內容
- 素材 +46（餐飲／零售／娛樂／服務都有，新的解鎖條件：商場等級、供應商關係、常客故事）。
- 隱藏配方 +37（新業態專屬，線索散在常客、供應商、對手與商場等級裡）。
- 常客 +12（橋本大叔、花婆婆、莉奈、武志、綾子、里歐、俊、賢、紀子、馬可、由奈、空），各有兩段故事。
- 品牌名組合：前綴 60 × 後綴 6–12（依類型），再加上 AI 內容池的品牌名（見 `docs/ai-content.md`）。

## 研發素材依業態分池
- 每個業態（84 種）各自一組素材：手搖飲看到茶、鮮乳、水果，拉麵看到麵與湯頭，書店看到紙與裝幀。研發工坊與伺服器的 `startRnd` 都依 `ingredientFitsCategory`（`shared/src/game/workshop.ts`）過濾；公開的 `IngredientInfo.categories` 就是「這個素材給哪些業態用」，不含隱藏特性。
- 資料在 `server/src/sim/`：`ingredientPools.ts`（業態**家族**，如 `noodle`＝拉麵／烏龍麵／蕎麥麵；以及既有素材各給哪些家族）、`ingredientsExtra.ts`（約 200 種家族／業態專屬素材）、`ingredientKit.ts`（型別與建構器）、`recipes.ts`（既有素材、配方，最後合併並展開成 `categories`）。
- 新增業態時：把它放進某個家族（`FAMILIES`），再補素材；`server/src/workshopPools.test.ts` 會檢查每個業態的主料／調味／手法各 ≥ 3 個（至少 1 個一開始就有）、特色 ≥ 1、沒有兩個業態的素材池完全一樣，而且既有配方在它指定的業態裡做得出來。
- 舊存檔：`syncWorkshop` 會回填已認識素材的 `categories`；新增的起始素材靜默加入，其他來源一次超過 3 個就合併成一則通知。
- 工坊畫面按樓層分頁（`client/src/screens/Workshop.tsx`）：先選樓層，再選那一層的店；筆記的素材圖鑑也只列所選樓層的業態。

## 平衡
擴充後以機器人重跑：勤勞策略 160 天約 ¥195M、無破產、Lv.6；放著不管的策略仍穩定緩慢賺錢。（擴建與更多店面把後期現金多吃掉一些。）
