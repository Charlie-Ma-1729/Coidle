## 集團
- `MallState.group?: { name, foundedTick }`（可選欄位，舊存檔沒有、不升版）。指令 `foundGroup { name }`、`renameGroup { name }`。
- 設立條件：商場 Lv.5、累計營收 ≥ ¥500M（勤勞玩家約第 80–100 天；原本 Lv.4／2 億，2026-11-29 調高）、資金付得起設立費 ¥10M（記為費用，不退）。名稱 1–16 字（`cleanGroupName`）。
- **只有掌權者**（持股過半的實際控制人；沒有就是創辦人）能設立、改名、開辦事業（`MallService.runCommand` 的 `assertAuthority`）。日常經營（`staffingOps`、處理事件）沿用現有規則：有股份的成員都能做。
- 集團是「商場成為母公司」：事業的收支併進這座商場的日報與稅，沒有新的資金進出路徑（`equity.md` 原則 4 的封閉清單不變）。

## 事業骨架（`MallState.ventures`）
- `ventures?: { staffing?: StaffingState }`（可選欄位）。每日結算 `venturesDaily(s, time)` 在 `step.ts` 的日結段、**日報之前**執行：營收進 `today.revenue`／`totalRevenue`／銷項稅，成本進 `today.fixed`，所以日報、損益、稅、財務頁自動涵蓋。純函式、只認 tick、決定性。
- 指令：`foundVenture { kind }`（開辦費）、`staffingOps { workers?, classes?, priceMult?, tuitionMult?, focus? }`、`resolveStaffingEvent { optionId }`。
- 之後的事業照這個樣子加：`VenturesState` 加一個鍵、`ventures.ts` 加規則、`sim/ventures.ts` 加每日結算與指令、畫面加一張卡。

## 人力派遣・教育：玩法（對照「深度與可玩性」七項）
1. **日常決策**：派遣人數（招募 ¥180k／人、資遣要付 5 天薪水）、班級數（開班 ¥1.2M、關班免費但再開重付）、派遣報價與學費倍率（約 ×1.2 內客人接受，再高流失）、專攻哪一條線。
2. **事件與風險**：季節（四月新年度與新學期最旺、年末補人、盛夏派遣淡季、一月受験期；假日派遣少）；每天 6% 機率出事件（勞動局查契約、大客戶縮編、同業挖角），每個事件 2 個選項（花錢保平安 vs 不花錢賭風險），2 遊戲日內不處理就自動採預設；風險用 `(種子, 日, 選項)` 的雜湊決定。
3. **成長與專精**：兩條線各有專精度（有開的線每天 +1，專攻的線 +1.5）；專精度讓**單價**最多 +12%（遞減、`specMult`），專攻的線拿滿、另一條拿一半。**專攻槽／專精度是通用層**（`specMult`、`DISTRACTION_MULT`、`MULTI_LINE_FEE`），之後的事業共用。
4. **與商場互相牽動**：需求隨商場店數放大（每多一間店 +3%，以 5 間為基準）；研修班三班以上、教育經驗滿 60，商場店員的研發手藝 +1（`trainingSkillBonus`，進 `chefLevel`）。
5. **取捨與失敗**：人與教室閒置照付；兩條線都開要付 2.5% 管理費、不專攻還分心打 94 折；人數超過需求就是浪費；定價超過 ×1.2 掉得比賺得快。
6. **互動**：**這一批沒有**（與其他玩家／NPC 的派遣合作留到事業互相有往來時再做；對關係企業的派遣必須以公開價，規則已寫在 `future-industries.md` ⑨）。
7. **可讀的成果**：集團頁顯示人員／班級／累計損益、昨天的需求與成交、近 30 天損益、季節係數、事件卡與選項說明。

## 平衡（`ventsweep.ts`，全年、純函式）
店數 8／20／36、等級 5／6／7，一年（從四月起算）：
- 只開派遣（20–25 人）回收約 230–275 天；加 2 班並專攻派遣約 200–225 天；全開約 210–265 天；**報價 ×1.2 最好**（約 130–200 天，與其他系統的最佳點一致）。
- **不專攻**的兩線全開比單開派遣差（分心＋管理費）；**專攻**比不專攻多賺約四到五成——專精有報酬、貪多不專攻沒有。
- 班級只有在「班數 ≈ 想上課的人 ÷ 30」附近才賺：班開太多（等級 6 的 4 班、等級 7 的 5 班）回收 > 235–330 天，旺季客滿、淡季虧。
- 派遣人員超過需求的那一截沒有邊際報酬（20 人 vs 40 人，一年淨利差不多），不會「越多越好」。
- 機器人（`ventrun.ts`，勤勞型 150 天、種子 101）：開／關終局資金差 −1.0M（雜訊內），事業累計 −17.3M（晚開、還在回收），近 30 天 +4.9M；沒破產。報酬是「略優於放著現金、遠低於本業邊際」，不是「必投」。
- 目標回收 150–250 天是計畫書給的暫定值；調整旋鈕：`STAFF_RATE`、`TUITION`、`TRAIN_BASE_POOL`、`CLASS_UPKEEP`、`SPEC_MAX`。
