# 帳號管理、管理後台、新手引導

## 帳號管理（玩家自己）
位置：**更多 → 團隊 → 我的帳號**（也出現在大廳）。
- 改暱稱、改密碼（改密碼後，其他裝置的登入會被登出，目前這台保留）。
- 刪除帳號：需要輸入密碼確認。若是商場的擁有者，必須先移交；若是商場最後一位成員，離開後商場一併解散。
- 商場擁有者可以：移交擁有權、踢出成員、重新命名商場。任何成員都可以離開（擁有者要先移交）。
- 忘記密碼目前沒有信箱可寄，請站長用管理指令重設（見下）。

## 管理後台（站長）
網址加上 `#admin`（例如 `https://你的網域/#admin`），輸入伺服器 `.env` 的 `ADMIN_TOKEN`（只存在這個分頁的 sessionStorage）。四個分頁：
- **概況**：使用者與商場數量、AI 預算。
- **AI 內容**：預算與內容池、立即生成（快訊／評價／事件／品牌名／商品名／常客）、待審事件與新常客的核准或拒絕、已上線內容的移除。
- **商場**：成員數、等級、資金、天數；區域與功能旗標（強制開放／關閉）；解散商場。
- **使用者**：重設密碼（產生臨時密碼，只顯示一次，並登出該使用者所有裝置）、刪除使用者。

沒有網頁時也可以用指令列：
```bash
npm run admin -- users
npm run admin -- malls
npm run admin -- reset-password <帳號>
npm run admin -- delete-user <帳號>
```

## 新手引導
- **首次進入商場**自動出現 7 頁導覽（歡迎、五個主要分頁、賺錢關鍵、時間與暫停、稅務、一起玩、新手任務）；可略過，之後從「更多 → 說明」重看。
- **新手任務**（10 項，完成當下自動領獎金，¥30,000–¥200,000）：逛逛店、調價、設營業時間、補貨、巡場、第一份日報、開新店、辦活動、試做研發、邀請朋友。總覽頁會顯示進度與下一項。
- **說明頁**：新手任務清單、常見問題（離線會怎樣、客人為什麼不來、資金為負、稅金、新鮮感、解鎖、招商 vs 直營、忘記密碼…）與名詞表。
