# 股權、撤資、股利與起始資金

多人合夥經營的商場，從一開始就有「股份」。商場的資產不拆分，股份只是比例；錢進出商場只有幾條規定好的路。

## 核心規則

| 項目 | 規則 |
| --- | --- |
| 股數 | 新商場發行 `INITIAL_SHARES` = 10,000 股，創辦人 100%。總股數會因為注資換股增加（`malls.total_shares`，上限 100 萬）。**所有比例都用「流通在外」算＝已發行 − 庫藏股** |
| 角色與股份 | 職位／`memberships` 管「誰能下指令」；`holdings` 管「分多少」。持有股份不能讓你操作商場 |
| 實際控制人 | 持股**過半**（> 50%）的現任成員，最多一位。創辦人頭銜（`is_owner`）永遠只有一個、不會變；有實際控制人時，**管事的是實際控制人**：請成員離開、轉讓創辦人頭銜、改名、換邀請碼、發股利、核准注資。創辦人自己仍可把頭銜交出去。沒有人過半時由創辦人管事（`MallService.authorityOf`） |
| 關係企業 | 持股 ≥ 20% 視同經手：被請出商場後仍是關係企業；持股掉到 20% 以下（賣掉、被稀釋）那一刻留下 `membership_trail`，一個賽季（28 天）內仍算 |
| 個人錢包 | `wallets(user_id, cash)`：賣股份、撤資、領股利的錢進這裡；用來注資換股、開第二座以後的商場、**買賣股票**（見 `docs/stock-market.md`）。每一筆進出都有錢包流水（`wallet_ledger`）。**算出來的持股價值不存**（持股比例 × 商場現金，加上錢包與股票市值） |
| 個人財務頁 | 自己的錢與股份集中在「個人財務」視窗（Lobby 與遊戲內共用）：總覽、商場股權（撤資／出價／轉讓、跨商場的出價與注資申請）、股市、明細。商場團隊頁的股權卡只留這座商場的股權表、注資換股、股利 |

## 退出與撤資

離開商場前**股份要先處理掉**（`leaveMall` 會擋，只有最後一位成員離開＝解散不受限）。兩條路，都可以只處理一部分：

1. **賣給其他股東**：出價（`share_offers`，同時最多 5 份、3 天有效）→ 被出價的人同意、錢包付得起才成交，**價格是出價當下的帳面價值**（持股比例 × 商場現金，不打折）。
2. **撤資（商場回購）**：照帳面價值 **9 折**，一次最多動用商場現金的 **50%**（超過請分次）；股份變成商場的**庫藏股**（不計入比例、不領股利），錢進你的錢包。商場至少要留一位股東。

被請出的成員不會被強迫賣股份（商場不一定付得起）；他仍是股東、不能下指令，持股 ≥ 20% 仍視為關係企業。

## 股利

管事的人宣布（`declareDividend`）：一次最少 1 萬、最多商場現金的 **30%**、兩次之間隔 **2 真實天**（約 12 遊戲日）。按持股比例分給每位股東（`floor`，零頭留在商場），庫藏股不領；股東收到時**扣 20% 所得稅**（稅款離開遊戲，`DIVIDEND_TAX_RATE`）。商場支出＝各股東稅前加總。

## 注資換股

成員從個人錢包投入一筆錢，照**帳面價值每股**（商場現金 ÷ 流通股數，不低於 ¥100）換股份，錢進商場：**先買庫藏股，不夠再發新股**。原股東比例被稀釋，但每股帳面價值不變。要由管事的人同意（申請 3 天有效，可撤回）；管事的人自己注資就直接成交。

## 起始資金是「每位玩家一次」

- 每位玩家只有一份免費起始資金（`INITIAL_FUNDS` ¥2,000,000）：用在**第一座開的商場**，或**第一次加入的商場**（加入時自動投入，照當下帳面價值換股份）。
- 之後每開一座新商場，要從個人錢包拿出同樣一筆錢（`chargeFounding`，只在 `POST /api/malls` 收；測試用的直接建立與 Overseer 不收費）。所以多開帳號、多開商場都不能憑空生錢。
- 5 個人合開的商場就有 5 份起始資金，而不是 1 份。

### 已在營運的商場（只跑一次）

營運中的商場成員沒各自投入過起始資金。**不重算現有資金**：創辦人那份 200 萬視為他的起始資金，創辦人 100%。要補成「每人一份」：

伺服器上用指令列（要**先停服務**，因為它會改商場資金，服務還在跑的話記憶體裡的舊資金會蓋掉它）：`npm run admin -- settle-grants <商場編號> --service-stopped`；服務開著時也可以用 Overseer 呼叫 `POST /api/admin/malls/:id/settle-grants`。兩者都寫稽核紀錄，都是 `MallService.adminSettleGrants`——每位還沒用過起始資金的成員補一份 200 萬進商場、標記已用，並讓**所有人（含創辦人）均分股份**，是「大家一起創業、各出一份」的算法，不是照目前帳面價值買進。例：5 人商場 → 補 800 萬，每人 20%。只在創辦人仍持有全部股份時才做；做過再執行不會再補（`founded_count` 已標記）。

## 設計原則（之後也要守）

1. **角色與股份分開**；持有股票不能讓你操作商場。
2. **商場資產不拆分**：個人財產＝持股比例 × 商場價值 + 錢包，是計算，不是搬動資產。
3. **整數股**；任何動股份的地方都維持「持股總和 + 庫藏股 = 已發行」（測試有檢查）。
4. **錢進出商場只有四條路**：股利（按比例、扣稅）、撤資（9 折、有上限）、注資換股（帳面價值）、起始資金（每人一次）。不要再開第五條。股票市場只動**個人錢包**，商場資金碰不到它。
5. **持股也是關係人**：任何跨商場規則，判斷是不是關係企業一律呼叫 `repo.areRelated`（已含成員、離開紀錄、≥ 20% 股東）。

## 未來怎麼延伸

1. **更真實的估值**：`wealth()` 與所有「帳面價值」現在只算商場現金。換成「現金 + 店面與設備折舊價值 + 營收倍數」，並做平滑與上限，避免單日波動被操作。換估值只需改 `stakeValue` 與 `issuePrice` 取用的那個數，其他不用動。
2. **投票與股東權利**：資訊權（持股人不是成員也看得到概況）→ 重大決議（改名、解散、股利比例）按持股投票，過半通過。實際控制人是它的特例，之後可以把「管事」拆成可投票的決議。
3. **IPO 與股市**：`share_trades` 結算、股價用伺服器 tick 的決定性序列；已經有 `total_shares` 可變、庫藏股、注資定價，IPO 就是「釋出一批新股賣給市場」。要補：關係人不能互相買賣、內線禁止交易期、金融操作用更嚴的落後門檻（見 `docs/roadmap-extensions.md`）。
4. **退場結算與解散**：現在最後一位成員離開＝解散，被請出的股東的股份會一起消失。補上清算：現金按持股分給股東（先扣債務與稅）。
5. **撤資的細節**：折數與上限可依持有時間調整（剛加入不久就撤資打更多折，防止「進來—撤資—拿走一部分商場現金」）；鎖定期；撤資冷卻。
6. **證券交易所得稅與稅制**：股利現在固定扣 20%；賣股份的資本利得、贈與（無償轉讓）的贈與稅，可以加進 `shared/src/game/tax.ts`。
7. **多帳號串通**依然擋不到：要靠 Overseer 看 `trades`、`share_offers`、稽核紀錄。

## 已知限制 / 待你決定

- 加入商場時自動投入起始資金並拿到股份；**之後退出一定走回購（9 折）或賣給其他股東**，立刻退出會損失約 10%，且錢包可能不足以再開一座商場（要 200 萬）。若覺得對新手太嚴，可以加「剛加入 N 天內撤資不打折」。
- 錢包的錢可以拿來注資、開新商場、買賣虛構集團的股票；沒有玩家之間轉帳（刻意不做，避免洗錢與串通）。
- 刪帳號時錢包的錢隨帳號消失，股份歸還給該商場現在管事的人。
- 兩個不同帳號串通無法由規則分辨。
