# 日本法規與稅務

目標：讓經營有「日本的味道」——該繳的稅、該辦的手續、該遵守的規定都真實存在，但**不讓玩家覺得繁瑣**。

## 設計原則
1. **全部自動處理**：帳單到期自動從資金扣款，玩家不需要手動申報、繳費或填表。唯一要留意的是「帳上要有現金」。
2. **只在兩處需要玩家決策**：開店時的許認可（顯示規費與時間）、挑供應商時的發票制度（便宜的小供應商進項稅額只能部分扣抵）。
3. **一個畫面看完**：「更多 → 稅務」顯示待繳帳單、繳納紀錄、預估年度稅額，以及用白話寫的規定摘要。總覽只在「30 天內要繳的錢大於帳上資金」或「有逾期」時才跳警告。
4. **對現金流友善**：錢不夠時先繳一部分、餘額每天加收延滯稅（約年率 7.3%），而不是直接懲罰或破產；賺到錢自動補繳。虧損可結轉。

## 實作了什麼（對照日本制度）
| 項目 | 遊戲裡的做法 | 對應制度 |
|---|---|---|
| 消費稅 | 價格都是含稅價。店內用餐、服飾、娛樂、服務 10%；外帶食品與飲料（超市、手搖飲、和菓子）8%；診所與認可托育不課稅。每季結算「銷項 − 進項」，進項大於銷項則退稅（還付） | 消費稅法、輕減稅率 |
| 發票制度 | 小型供應商（山下食肉、港口鮮魚組合…共 9 家）沒有登錄，進項稅額只能扣一部分：2026/10–2028/9 70%、～2030/9 50%、～2031/9 30%、之後 0%（2026 年度稅制改正後的過渡措施） | インボイス制度 |
| 法人稅等 | 會計年度 4–3 月；4 月決算、5 月底前繳；10 月預繳上一年稅額的一半。法人稅 15%（800 萬圓以下）/23.2%，加地方法人稅 10.3%、住民稅法人稅割 10.4%、事業稅 3.5/5.3/7.0%、防衛特別法人稅（超過 500 萬的部分 × 4%）、均等割每年 18 萬。虧損全額結轉。實質稅率約 33–36% | 法人稅法、地方稅法 |
| 固定資產稅・都市計畫稅 | 大樓本體評價 15 億圓＋店面投資額，約 1.7%/年；6、9、12、2 月各繳四分之一 | 地方稅法 |
| 社會保險 | 雇主負擔約 15.8%（健保＋育兒支援金、厚生年金 9.15%、雇用保險、勞災、兒童津貼拠出金），上個月薪資的比例，每月繳 | 健保法、厚生年金保險法、雇用保險法 |
| 獎金 | 6、12 月各發 0.4 個月薪資（含社會保險） | 日本的賞與慣例 |
| 勞動基準法 | 深夜（22–5 點）與每天超過 14 小時的班次，薪資加成 25%；營運頁會顯示人事成本係數 | 勞基法（深夜割增、時間外割增） |
| 許認可 | 開店時依業態辦手續：飲食店營業許可（保健所）、深夜酒類提供飲食店營業申報（居酒屋、酒吧）、風俗營業許可（電玩中心，審查最久）、藥品販售業登錄、診所開設申報、旅館業許可等；有規費與審查時間 | 食品衛生法、風營法、藥機法、醫療法、旅館業法 |
| 著作權使用費 | KTV 營收的 2.5%，每月結算 | 著作權法 |
| 衛生・消防稽查 | 既有的稽查系統（前一階段完成） | 食品衛生法、消防法 |

## 法律糾紛（客訴升級成訴訟，2026-11 新增）
多數客訴照舊（道歉、招待、退費、婉拒）。**處理不當的嚴重客訴、管理不善的店、以及某些事件（例如過敏事故）**會升級成法律糾紛，依日本民事程序走：**請求書（内容証明郵便）→ 示談交渉 → 民事調停（簡易裁判所）→ 訴訟**；請求金額 60 万円以下是**少額訴訟**（一次開庭結案、期限較短）。程式在 `server/src/sim/legal.ts`，資料與數學在 `shared/src/game/legal.ts`，畫面在「客人」頁的「法務」區。

### 每個業態有自己的糾紛（資料驅動；`legalKindsFor(category)`，測試保證 84 種業態、8 個區域都有）
| 糾紛 | 適用法規 | 誰會遇到 |
|---|---|---|
| 食物中毒 | 食品衛生法、製造物責任法（PL法）、民法709條 | 餐飲（B1、高樓層餐飲、廣場餐車、1F 餐廳） |
| 過敏事故 | 食品表示法（過敏原標示）、民法709條／415條 | 餐飲 |
| 商品瑕疵 | PL法、消費者契約法、民法562條（契約不適合責任） | 零售（1F、3C 文創、跳蚤市集） |
| 不當標示 | 景品表示法、消費者契約法（撤銷權） | 零售、餐飲 |
| 設施事故 | 民法717條（工作物責任）、民法709條、安全配慮義務 | 娛樂、廣場、生活服務、商務旅宿、3C 文創 |
| 個資外洩 | 個人情報保護法、民法709條 | 生活服務、商務旅宿、1F（美妝、藥妝、便利商店） |
| 施術糾紛 | 民法415條（債務不履行）、709條、醫療法 | 診所、牙科、SPA、美容、美甲、瑜伽、健身、托育 |
| 住宿糾紛 | 旅館業法、民法415條、消防法 | 旅館、膠囊旅館、行李寄放 |
| 契約糾紛 | 民法415條、消費者契約法、特定商取引法 | 共享辦公、會議中心、旅行社、活動場地、補習班、影印、寫真館 |

### 流程與選項（`legalOptions`）
| 階段 | 期限 | 選項 |
|---|---|---|
| 請求書 | 4 天 | 示談（付請求額 80%，含保密、不影響口碑）／自己協商（成功約 35%）／委任律師（費用＋大幅提高成功率，約 30%）／拒絕（直接進調停） |
| 民事調停 | 5 天 | 接受條件（50%）／自己出席／律師陪同／不出席（過料 ¥50,000，調停不成立 → 訴訟） |
| 訴訟 | 6 天（少額 3 天） | 裁判上的和解（50%）／自己應訴／律師應訴。判決：駁回（口碑 +0.4）、部分認容（35–65%，口碑小扣）、全部認容（100% + 遲延損害金 5%，口碑大扣、可能被稽查） |
- **原告占不占理是隱藏的**（由種子、案件編號與起因客訴的語氣決定，不存進狀態），玩家只能從客訴語氣猜；你的**證據力**（成立當下的清潔、設備、稽查合規分數、店面新鮮感）與**律師**（+15）決定勝算：`plaintiffStrength` → `judgmentOdds`／`settleChance`。
- 逾期沒處理就依「客訴處理偏好」（soft／balanced／firm）自動應對；沒錢時退回不花錢的選項。亂數由 (seed, 案件, 階段) 決定，和處理的時間點無關。
- 同時最多 2 件，兩件之間冷卻 14 天；律師費 ¥150,000 + 請求額 5%。
- **賠償責任保險**：基本（每店每日 ¥1,200、給付 50%、每件上限 150 萬、自負額 5 萬）、完整（¥3,000、80%、600 萬、3 萬）；只給付和解金與判決金，不含律師費與過料；以案件**成立當下**的投保等級為準，所以要事前投保。
- 觸發來源：①嚴重客訴（髒、設施、品質、價格）處理不當或逾期（`maybeEscalateComplaint`；語氣越兇、越拒絕越容易，賠償／退費大幅降低機率；機率約 0.6%～4%，再乘上處理方式（婉拒 ×2.5、逾期 ×1.5、退費 ×0.35））；②事件效果 `legalRisk`（過敏事故選「請客人自己注意」45%、「說明已有標示」10%）；③每日 `legalDaily`：髒、設備差、合規分數低的商場會被告（管理良好時約每 250 天一次，最差時約每 40 天一次）。
- 敗訴後 `nextAt` 會把對應的衛生／消防稽查提前（`LEGAL_KINDS[kind].inspection`）。
- 費用計入 `repairs`（和日報的「修繕・罰款」同一欄），另記 `today.legalCost`；保費計入固定支出。

## 沒有做的
- 沒有律師的個別等級、陪審、上訴、集體訴訟、刑事責任與行政處分（營業停止命令）以外的法律後果。
- 民事調停與訴訟的實際金額、期限與費用為遊戲化的簡化，**不是法律建議**。
- 沒有逐筆申報、帳簿、請款單或發票開立；沒有年末調整、源泉徵收、住民稅（員工側）。
- 沒有大店立地法、建築基準法定期報告、防火管理者選任、36 協定、有薪假；勞動法規只以「薪資加成」表現。
- 稅率與日期以 2026 年度為基準整理，查證來源：國稅廳與財務省、各縣廳資料與民間會計網站（2026 年度稅制改正後的發票制度過渡措施為 70%／50%／30%）。中小法人 15% 軽減稅率在現行法適用到 2027 年 3 月，遊戲假設會延長。
- **這是遊戲，不是稅務建議。**

## 對平衡的影響（機器人模擬，120 個遊戲日）
- 稅金與社會保險吸走約 20–25% 的累積資金：勤勞玩家第 120 天約 1.2 億（原本 1.6 億），放置玩家約 0.63 億（原本 0.83 億）。
- 這同時解決了上一輪的「後期資金堆積」問題：現金越多、帳單越大，仍是正成長，不會破產。
- 放置玩家人氣約 44–46，低於升級門檻 48，會停在 Lv.1：長期沒人照顧的商場不會自己升級（原本就有的「溫和但有感」的懲罰）。
