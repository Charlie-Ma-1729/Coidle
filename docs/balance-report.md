# M5 平衡報告（機器人模擬）

工具：`npm run sim -- <天數> <種子數> <策略>`（策略：diligent / tender / periodic / lazy / chaotic）、`server/src/bots/ablate.ts`（單一玩法消融）。
回歸測試：`server/src/balance.test.ts`。1 遊戲日 ＝ 真實 6 小時。

## 調整前發現的問題
| 問題 | 證據 |
|---|---|
| 放著不管比認真玩還賺 | 同樣 5 間店，「勤勞」60 天後資金低於「完全放置」；所有選配玩法加起來只多 6% 營收 |
| 人氣幾乎不受照顧影響 | 勤勞與放置的人氣只差約 3 點 |
| 商場一大，清潔與設備就崩 | 15 間店時清潔 16、設備 7（即使調到最高等級也追不上），滿意度被拖垮、頻繁故障 |
| 暫停太頻繁 | 放置玩家平均每遊戲日 0.40 次（約每真實日 1.6 次），其中一半是稽查預告 |
| 錢沒地方花 | 第 30 天起所有區域蓋滿、升滿，資金一路堆積 |
| 常客親密度偏快 | 勤勞玩家第 60 天全員滿格 |

## 調整
- **稽查預告只在「預設備戰仍過不了」時才暫停**（`inspectionAtRisk`）；狀況好的商場放著也會合格。
- **品質對滿意度的影響加大**：滿意度 = 0.16 + 0.62×品質（原 0.28 + 0.4×品質）；新鮮感對品質的折扣改為 0.5 + 0.5×新鮮感。
- **清潔／維護能力與費用隨店數放大**（`facilityScale`：5 間店為 1 倍，15 間約 2.2 倍）。
- **成本**：建店 ×1.5、翻新 ×3；促銷費用下調約 30%（原本幾乎是賠錢）。
- **升級門檻**：L3 1.2 億、L4 3.5 億、L5 8 億、L6 15 億、L7 26 億、L8 42 億（原本 0.9／2.2／4.5／8／14／22 億）。
- **常客造訪的親密度增量 ×0.75**（招牌帶來的額外加成另計）。

## 調整後的結果（3 個種子平均）
| 指標 | 結果 |
|---|---|
| 完全放置 vs 照顧同樣 5 間店（60 天） | 營收 1.43M vs 1.57M／日（+10%）；人氣 43 vs 50.6 |
| 單一玩法的價值 | 換菜單最划算（+6% 營收、淨資金增加）；常客互動、研發、促銷接近持平，但帶來人氣與長期內容 |
| 暫停頻率（放置） | 每遊戲日 0.13–0.19 次（約每真實日 0.5–0.75 次），來源都是供應商戲劇事件 |
| 勤勞玩家進度 | L2 約第 30 天、L3 第 45 天、L4 第 75 天（約 19 個真實日） |
| 亂設定玩家 | 會破產，但改回合理設定 20 天內資金與人氣都恢復，沒有死局 |
| 常客 | 勤勞玩家第 45 天平均親密度約 69，仍會在第 75 天前後滿格 |

## 仍待觀察（上線後滾動調整）
- 資金仍會在後期堆積（第 120 天約 1.6 億），需要科技樹、出租招商等新的資金出口。
- 促銷與研發的直接回報偏低，主要價值在人氣與內容；如果玩家覺得不值得可再放寬。
- 對手排名：勤勞玩家長期第 1，放置玩家會掉到第 2–4。若覺得太簡單，可以調高對手成長率。
- 機器人無法判斷「好不好玩」，節奏要看真人回訪狀況。

## 多商場模擬（跨商場互動）

指令：`npx tsx --tsconfig tsconfig.json server/src/bots/world.ts [種子]`（另有長跑的不變量測試 `server/src/world.sim.test.ts`，每次跑測試都會驗證）。

設定：4 座真人商場（各給 ¥30M、不做任何經營，只做跨商場行動）＋ 8 座 NPC 商場，跑 3 個賽季（86 天）；每 6 個真實小時，每座商場有一半機率隨機做一件事：提出結盟、回覆邀請、聯名活動、送資金、調貨、搶客、被搶客後反擊、結束協議。種子 20270101 的結果：

| 行動 | 成功 | 被擋 |
|---|---|---|
| 提出結盟 | 31 | 56 |
| 回覆邀請 | 6 | 0 |
| 聯名活動 | 9 | 4 |
| 送資金 | 24 | 50 |
| 調貨 | 3 | 91 |
| 搶客 | 83 | 5 |
| 反擊（被搶客後打回去，同一客群） | 57 | 5 |
| 結束協議 | 3 | 0 |

- **規則真的擋得住人**：被擋最多的是「貿易只能和真人商場」（隨機對象多半是 NPC）、「NPC 覺得你們還不夠格」（分數差 > 8 不結盟）、「最多只能轉出庫存的一半」；搶客與反擊被擋的原因是對方還在保護期。
- **沒有人被壓垮**：4 座商場最後資金為 25.2M／39.9M／33.9M／29.9M（−16%～+33%）。最低的那座主要是出手花掉的錢（每次 ¥100k × 等級），不是被打掉的營收；單次被搶客的損失另有回歸測試守住（`compete.test.ts`：一週營收損失 < 15%）。
- **貿易守恆**：24 筆資金互送共 ¥5.0M、3 筆貨物 118 份；對方收到的永遠 ≤ 轉出的 95%，任何 7 天視窗的淨流量都在上限內（`world.sim.test.ts` 逐筆檢查）。
- **反擊是搶客的特例**：沿用同一套冷卻、每日次數、保護期與資格限制，沒有額外優惠，所以不會讓互打無限升級；對方在保護期時反擊會被擋（上表 5 次）。
- 賽季 1、2、3 都結算，每座商場每季最多領一次獎勵。

待觀察：真人商場數量很少時，NPC 結盟與商戰是主要互動對象；上線後看實際結盟率與搶客頻率，再調 `COMPETE_*` 與 `ALLIANCE_*` 常數。
