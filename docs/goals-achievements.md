# 目標、團隊事件、成就與線索

## 區域專屬事件
除了通用事件，每個區域（1F、娛樂、3C 文創、生活服務、高樓層餐飲、活動廣場、商務旅宿）都有 4–6 個專屬事件，**區域開放且那一區真的有店**才會發生。例如：新機發售日、夏日煙火大會、旅行團集體住房、新年健身房爆滿、美食評論家悄悄來訪。多數有取捨選項，沒人處理就採預設，不會讓時鐘暫停。（`shared/src/game/events_zones.ts`）

## 每日與每週目標（更多 → 🎯 目標）
- 每天 3 個、每週 3 個，依商場等級與功能（招商、科技）挑選；目標數字依**近 7 天的表現**換算，所以不會太簡單也不會遙不可及。
- 日目標在日結算時驗收、**自動發獎金**（約當日營收的 0.3–0.6%）；週目標三項全達成，週結算再多 50% 獎金與一點口碑。
- 沒達成沒有任何懲罰。

## 團隊事件
- 偶爾出現（颱風前防災、跨年籌備、夏日祭典、春季大掃除、週年慶），需要 **min(成員數, 3) 位不同的隊員**各認領一項任務（各花一點錢）。
- 期限 3 個遊戲日（標準流速約 18 個真實小時）。湊滿就完成，拿獎金與口碑；來不及但有人做了一部分，拿部分回饋；沒人做，只是錯過，沒有損失。
- 不會讓時鐘暫停。
- **隊員貢獻**：目標頁列出每位隊員做過幾件事、完成幾項團隊任務（只列貢獻，不排名懲罰）。

## 成就與評鑑（更多 → 🏆 成就）
- 37 個成就（營運時間、營收、等級、店數、常客、客服、研發、供應商、招商、科技、稅務、稽查、團隊、目標、隱藏），解鎖發獎金，部分附**稱號**。隱藏成就解鎖前顯示「？？？」。
- **商場評鑑星級**（1–5 星）：由商場等級、整體口碑、稽查合規、店家規模與多樣性、成就數量綜合，顯示在總覽。

## 線索收集與猜地點
- 20 則含蓄的線索（串炸店牆上的告示、章魚燒師傅的話、老街的高塔、機場直通車…），依經營過程中遇到的事與開的店逐步發現，**全部不點名真實地名與品牌**。
- 集到一些線索後可以猜「這座商場在哪裡」：每個遊戲日一次，答案只以**雜湊**比對（程式碼與畫面都不含答案），猜中解鎖隱藏成就並得一筆大獎金。
